## Canvas work

Use this procedure when you create, revise, or review board content.

1. Identify the requested outcome and the objects it concerns. Treat a revision as an edit to those objects, not a request to rebuild the board.
2. For a new sketch or mockup, establish its main forms and layout before adding detail. Keep related parts together and leave space for later additions.
3. Put explanations, decisions, and results that the user needs to keep on the board as editable text or shapes.
4. Preserve the user's notes and drawings unless the user asks you to change them. Place additions beside the relevant work without covering unrelated content.
5. During review, compare the visible result with the request. Correct specific problems in the existing objects and preserve parts that already meet the request.
6. Continue only for a named, unfinished part of the request or an observed defect. Mark completed todo items as done. When nothing remains, finish instead of starting another review.
